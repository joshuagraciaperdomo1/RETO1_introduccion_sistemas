# RETO1_introduccion_sistemas
Radar de Desvíos (Reto No. 1 - Introducción a la Ingeniería de Sistemas, Unimagdalena). Aplicación web con Leaflet y GeoJSON para visualizar puntos críticos viales, reportes ciudadanos y rutas alternas por tipo de vehículo en el corredor Calle 29H hacia la Universidad del Magdalena, Santa Marta.
